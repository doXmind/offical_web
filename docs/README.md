## 🚀 快速开始

### 新开发者入门

1. **阅读顺序**:
   - 先读 `DEVELOPMENT.md` 了解项目全貌
   - 查看 `PROGRESS.md` 了解当前进度
   - 根据任务查看 `PAGE_SPECS.md` 相应章节
   - 开发时参考 `STYLE_GUIDE.md`

2. **开始开发**:
   ```bash
   # 安装依赖
   npm install
   
   # 启动开发服务器
   npm run dev
   
   # 访问 http://localhost:3000
   ```

3. **选择任务**:
   - 查看 `PROGRESS.md` 中的待办任务
   - 选择合适的任务开始开发
   - 更新进度状态

## 🎯 项目目标

创建一个专业、现代、高性能的企业官网，展示doXmind作为AI智能文档平台的核心价值。

### 设计理念
- **极简主义**: 黑白主色调 + 蓝色(#11c4d4)点缀
- **内容优先**: 清晰传达产品价值
- **企业级**: 专业、可靠、值得信赖

## 🛠 技术栈

- React 18 + Vite
- Tailwind CSS
- Headless UI
- Lucide React Icons
- React Router (待实现)
